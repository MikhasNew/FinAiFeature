## 4 Января 2026 - Доработка UI Статистики и Прогнозирования

### 1. Рефакторинг Карусели Статистики (`Counter.razor`)
- **Слайд "Баланс"**: 
    - Контент отцентрирован по вертикали и горизонтали.
    - Убраны лишние отступы для гармоничного вида.
- **Слайд "Динамика" (График)**:
    - График растянут на всю ширину экрана (убраны боковые `padding`).

### 2. Новый Функционал: Финансовый Прогноз
Добавлен новый 6-й слайд в карусель: **"ФИНАНСОВЫЙ ПРОГНОЗ"**.

- **Логика (`MainViewModel.cs`)**:
    - Добавлен метод `CalculatePredictionStatistics`.
    - **Определение текущего баланса**: Берется из последней транзакции с `Balance > 0` или высчитывается как `TotalIncome - TotalExpense`.
    - **Прогноз поступлений**: Анализируются поступления (`ZACHISLENIE`) за последние 90 дней. Выделяются "значимые" поступления (>20% от макс.), находятся частые дни месяца (например, 5-е и 20-е число).
    - **Рекомендация по тратам**: Рассчитывается `DailyBudget = CurrentBalance / DaysUntilNextIncome`.

- **UI (`Counter.razor`)**:
    - Отображение Текущего баланса крупным шрифтом.
    - Дата следующего ожидаемого поступления и количество дней до него.
    - Рекомендуемая сумма ежедневных трат (зеленым цветом).

## 4 Января 2026 (Продолжение) - Импорт из PDF

### 1. Восстановление импорта банковских выписок (PDF)
- **MainViewModel**:
    - Добавлен метод `ImportPdfAsync()`, который вызывает `ProcessPdfFileAsync`.
    - Метод использует `IFileService.PickFileAsync` с фильтром по расширению `.pdf`.
- **UI (MainLayout.razor)**:
    - В главное меню додавлена кнопка "Import from PDF" (Импорт из PDF).
- **WebFileService**:
    - Доработан метод `PickFileAsync` в `WebServices.cs`. Теперь он корректно фильтрует файлы по списку расширений (patterns), а не только `*.xml`. Это позволяет выбирать PDF файлы из папки `Downloads` при отладке в браузере.
- **Backend**:
    - Подтверждена работа `Parser.cs`, использующего библиотеки `Tabula` и `PdfPig` для извлечения данных из таблиц PDF выписок.

### 2. Новая страница: "Управление данными"
Создан централизованный узел для всех операций с данными:
- **DataManagement.razor**:
    - Разделы: "Импорт" (PDF, XML), "Экспорт" (XML), "Опасная зона" (Очистка БД).
    - Улучшенный UI с карточками и соответствующими иконками.
- **NavMenu.razor**: добавлен новый пункт меню "Данные" (Data).
- **MainLayout.razor**: очищено основное меню (кнопки импорта/экспорта удалены оттуда для избежания дублирования и упрощения интерфейса).

### 3. Управление правилами парсинга
Добавлена возможность редактирования правил обработки SMS и PDF прямо из интерфейса приложения:
- **SmsRules.razor**:
    - Страница со списком всех настроенных банков.
    - Функции добавления, редактирования, копирования и удаления конфигураций.
- **BankRuleDialog.razor**:
    - Диалог с вкладками для детальной настройки:
        - **Основное**: название банка и SMS-идентификатор.
        - **SMS Regex**: настройка регулярных выражений для суммы, даты, типа операции и т.д.
        - **Шаблоны**: управление ключевыми словами для определения типа транзакции.
        - **PDF (Импорт)**: настройка индексов колонок для парсинга банковских выписок.

### 4. Технические исправления (Cleanup)
- **Унификация именования**: Свойство `СashTemplates` (с кириллической 'С') переименовано в `CashTemplates` (латиница) во всем проекте для предотвращения ошибок компиляции и путаницы.
- **Исправление UI**: Увеличен лимит слайдов карусели статистики в `Counter.razor`. Теперь доступен свайп до 6-го слайда (Прогноз).
- **Коррекция моделей**: Исправлены обращения к полям `Descripton` (с опечаткой в модели) и `Mcc` в UI компонентах.
- **Обновление MudBlazor**: Код адаптирован под требования MudBlazor 7 (использование `IMudDialogInstance` и строгая типизация `MudChip`).
